离线翻译助手 使用说明
版本：1.0.0
================================

一、这是什么
--------------------------------
Windows 上的离线翻译程序。翻译在本机完成，不需要联网，也不用另外安装
.NET、Python 或其它运行库。

采用双推理引擎架构：
1. llama.cpp 原生引擎：支持 Vulkan / CUDA 硬件加速，用于通用 GGUF 模型
   （如 Qwen2.5 0.5B/1.5B、Hy-MT2 Q4/Q8 等）。有独显或集显时自动调用 GPU，
   极速出字；无显卡时自动回退 CPU。
2. HyMT2 纯 C# 引擎：专为随包自带的 Hy-MT2 1.8B（2Bit）设计，纯托管、
   超轻量、零外部动态库。

支持多模型热切换，支持中文、英语、日语、韩语、俄语、德语、法语、西班牙语、
葡萄牙语、意大利语、荷兰语、波兰语、土耳其语、乌克兰语、越南语、泰语、
印尼语、阿拉伯语等语言。句中出现的共享术语库里的术语会按词库译法输出。


二、如何安装
--------------------------------
把整个文件夹原样拷到目标电脑，保持下面的相对位置不要拆开：

    OfflineTranslator.exe
    models\              （内含 Hy-MT2、Qwen 等模型目录）
    使用说明.txt

只拷贝 exe、不拷贝 models 目录时，程序无法翻译。
建议放在本机磁盘，例如 D:\OfflineTranslator。路径里可以有中文和空格。
不需要安装，双击 OfflineTranslator.exe 即可。


三、第一次使用
--------------------------------
1. 双击 OfflineTranslator.exe。
2. 窗口上方状态会从「未加载」变为「已就绪」，并在上方「后端」显示实际
   计算硬件（例如：llama.cpp Vulkan GPU 加速 或 CPU）。
3. 在上方文本框输入原文，选择源语言和目标语言。
   源语言选「自动检测」时，程序会判断语种。
4. 点击「执行翻译」，或在输入框按 Ctrl+Enter。
5. 译文会边生成边显示，长文本不用等全部翻完。点击「复制译文」可复制。
6. 「⇄ 切换」对调源语言和目标语言。「清空」同时清掉原文和译文。
   翻译过程中可点「停止」。

推理线程保持 0 即可，程序会自动使用 CPU 的性能核。
对于 Qwen 或标准 GGUF，程序会自动尝试调用显卡 Vulkan GPU 进行全层加速。


四、术语库（只读共享）
--------------------------------
本程序不再提供术语编辑界面。翻译时自动读取与 WISDRICADTranslate、
InventorAI 共用的术语文件，句中出现的术语按词库译法输出，
整句与某条术语完全一致时直接采用该译名。

术语文件位置（UTF-8 编码 CSV，# 开头行为注释）：
    C:\ProgramData\WISDRI\Glossary\glossary.csv
每用户覆盖（存在时优先生效）：
    C:\Users\<用户名>\AppData\Roaming\WISDRI\Glossary\glossary.csv

两处都没有时使用程序内置的出厂术语。要增改词条请直接用 Excel
编辑上述 CSV（另存为 CSV UTF-8），或在管理术语的软件里维护，
也可以设置环境变量 WISDRI_GLOSSARY_DIR 指向自己的术语目录。


五、多模型切换与追加模型
--------------------------------
随包模型已提供：
    models\Hy-MT2\Hy-MT2-1.8B-2Bit.gguf （腾讯 1.8B 翻译专用大模型，专业翻译质量好）
    models\Qwen\Qwen3-0.6B-Q4_K_M.gguf （通义千问 Qwen3 0.6B 最新小钢炮，极速翻译）

程序启动时会自动扫描 models 目录及其所有子目录下的 .gguf，在「模型」
下拉框中选择。

- 想追求极致速度（尤其是普通笔记本、有核显/独显机器）：
  在下拉框选中 `Qwen3-0.6B-Q4_K_M.gguf`，走 Vulkan GPU 毫秒级极速出字。
  【默认关闭思考模式】：提示词与底层解码器已默认强力禁用并过滤思维链与
  <think> 标签，保证 100% 纯净直出最终译文，绝不浪费时间在多余思考上。
- 想追求更精准的专业机械与图纸术语翻译：
  在下拉框选中 `Hy-MT2-1.8B-2Bit.gguf`。
- 追加其它模型：
  支持直接将任意标准 GGUF 模型（如 Qwen3 其他尺寸、Llama 3 或 Hy-MT2 Q4/Q8）
  放入 models 目录下的任意子文件夹中，点「刷新」按钮即可在下拉框选中。
  选中后点击「切换到此模型」即可热切换（无需重启程序）。

程序会记住上次成功加载的模型，下次启动自动选中它。


六、本地 API（可选）
--------------------------------
给本机其它程序调用。只监听 127.0.0.1，不会对局域网开放。

1. 确认模型状态为「已就绪」。
2. 端口默认 21894，可改。
3. 点「启动 API」。点「复制地址」得到类似 http://127.0.0.1:21894 的地址。
4. 点「测试 API」验证服务可用：程序会真实调用一次翻译接口，
   结果显示在运行日志里（用输入框里的文字作示例，输入框为空时
   自动用 "Hello, world!"）。

翻译接口：
    POST /v1/chat/completions

示例：
    curl http://127.0.0.1:21894/v1/chat/completions ^
      -H "Content-Type: application/json" ^
      -d "{\"messages\":[{\"role\":\"user\",\"content\":\"检查装配体干涉\"}],\"source_language\":\"zh\",\"target_language\":\"en\"}"

自定义提示词 / 术语（把术语写在提示词里）：
    调用方可以在 messages 里放一条 system 消息，内容会作为额外提示词
    拼在翻译提示的最前面。适合传入临时术语表、译名要求或背景说明，
    例如：

    {
      "messages": [
        { "role": "system", "content": "术语要求：干涉检查 → Interference Check；装配体 → Assembly" },
        { "role": "user", "content": "检查装配体干涉" }
      ],
      "source_language": "zh",
      "target_language": "en"
    }

    也可以改用顶层字段 "system_prompt": "..." 传同样的内容。
    若整句只放在 prompt 字段（不传 messages），同样可以翻译。

source_language、target_language 使用语言代码，例如 zh、en、ja、de、ru。
不传 target_language 时默认译为中文。
模型未加载就启动 API 会被拒绝。关闭程序前可先点「停止 API」。


七、常见情况
--------------------------------
- 打开后停在「未加载」：检查 models\Hy-MT2 里是否有 .gguf，
  再点「刷新」「加载模型」。看窗口底部运行日志里的具体原因。
- 第一次双击稍慢：单文件程序会在本机展开运行时，只在第一次明显。
- 翻译一句通常在半秒内出首段文字，长文本边翻边显示。
- 相同原文、方向和提示词重复翻译时会直接复用上次结果，几乎瞬间返回。
- 译过的句子会记在本机，重启程序后仍然有效：
  %LocalAppData%\WISDRI\OfflineTranslator\translation-memory.jsonl
  删除该文件即可清空翻译记忆；更换模型或术语库内容后旧记忆会自动失效。
- 内存：随包 1.8B 模型大约需要 2GB 可用空间（模型文件约 573MB）。
  更大的模型按体积相应增加。模型文件请与 exe 放在同一文件夹。
- 杀毒软件若拦截 exe，请把整个文件夹加入信任后重新打开。
- 本程序不上传原文。断网也可以翻译。
